# 💰 Gerenciador de Gastos Pessoais (Finanças)

Aplicação web desenvolvida em Django para gerenciamento e projeção de gastos pessoais mensais. O sistema permite cadastrar despesas e visualizar uma projeção de gastos futuros (ex: parcelamentos) para um período de 12 meses.

## 🚀 Tecnologias Utilizadas
- **Backend:** Python / Django
- **Banco de Dados (Dev/Prod):** SQLite
- **Frontend:** Django Templates (HTML/CSS/JS)
- **Variáveis de Ambiente:** python-dotenv
